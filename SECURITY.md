## Reporting a Vulnerability

Security of user data and external storage is of critical importance to **Safe Drive Ejector Tool**.

If you discover a security vulnerability or disk data-safety flaw:
1. **Do not create a public issue on GitHub.**
2. Report the vulnerability privately to the project maintainer via GitHub:
   - [Siraj's GitHub Profile](https://github.com/siraj-bd)
   - Or open a private security advisory on the repository: [https://github.com/siraj-bd/Safe-Drive-Ejector-macOS/security/advisories](https://github.com/siraj-bd/Safe-Drive-Ejector-macOS/security/advisories)
3. Please include:
   - Type of issue (e.g., race condition in unmount, improper permissions, data corruption risk).
   - Detailed step-by-step instructions or proof of concept to reproduce.
   - macOS version and disk configuration details.

We will review the report, provide an initial acknowledgment within 48 hours, and coordinate a fix and release.
